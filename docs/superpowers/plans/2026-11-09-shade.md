# Shade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows tray app that transcribes both sides of an English call in real time, detects questions/tasks (or takes a hotkey / screenshot), and streams short AI answers into a window or a capture-excluded overlay, saving transcript and hints per session.

**Architecture:** A pure-Python core (audio → VAD segmenter → faster-whisper → `Transcript` → `Detector`/`Engine` → `Provider` stream → `SessionWriter`) that runs on worker threads and reports through a single `on_event` callback. A PySide6 UI layer receives those events through a Qt signal bridge and owns the tray, window, overlay, hotkeys and screenshot selection. Everything below the UI is unit-tested with fakes; audio/GPU/UI parts get scripted manual checks.

**Tech Stack:** Python 3.11 (uv), PySide6, sounddevice, PyAudioWPatch, soxr, numpy, faster-whisper (CUDA 12, cuBLAS/cuDNN wheels), silero VAD (ONNX), anthropic, openai, pynput, mss, nvidia-ml-py, tomli-w, pytest.

**Spec:** `docs/superpowers/specs/2026-11-09-shade-design.md`

## Global Constraints

- Windows 11 only; Python 3.11 via `uv` (`requires-python = ">=3.11,<3.12"`).
- Everything user-facing in English: UI, transcript, hints, saved files.
- Speaker labels come from the source: mic = `Me`, system loopback = `Them`.
- Target: first hint words visible within 2–3 s after "Them" stops speaking; hints always stream.
- Hint format: 1–3 sayable lines first, then optional short bullets, then code in one fenced block.
- Every Shade window calls `exclude_from_capture` (`SetWindowDisplayAffinity(hwnd, 0x11)`).
- Session files are appended and flushed on every write (crash-safe).
- API keys only from env vars (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `XAI_API_KEY`, `GROQ_API_KEY`, `DEEPSEEK_API_KEY`, `GEMINI_API_KEY`); never written to settings, logs or session files.
- Provider failures never stop transcription.
- Default Claude model `claude-opus-5-5` (effort `low`), detector `claude-haiku-5-5`; model ids are exact strings, no date suffixes.

## Review Focus

1. Missing API key, provider error or local server down → a short error appears in the hint area, transcription keeps running (test in Task 7).
2. A new question arrives while a hint is still streaming → the old one is cancelled and the new one starts; an auto-trigger never cancels a hotkey/screenshot hint (test in Task 7).
3. Silence, noise or Whisper hallucinations ("Thank you.", "you", empty) → dropped, never reach the transcript or the detector (test in Task 9).
4. Screenshot with a local model without vision → the exact message `Selected local model does not support images.` instead of a silent failure (test in Task 7).
5. Hour-long call → the model context is limited to `context_seconds`; transcript file only grows by appends (tests in Tasks 2 and 3).

### Task 7: Engine

**Files:**
- Create: `src/shade/engine.py`
- Test: `tests/test_engine.py`

**Interfaces:**
- Consumes: Tasks 2–6.
- Produces: `class Engine(provider: Provider, detector: Detector, transcript: Transcript, writer: SessionWriter, cost: CostMeter, profile_text: str, context_seconds: float, on_event: Callable[[Event], None], clock: Callable[[], float])`.
  Methods: `on_utterance(u: Utterance) -> None`, `ask_now() -> None`, `ask_with_image(png: bytes) -> None`, `set_auto(enabled: bool) -> None`, `auto_enabled: bool` (default True), `wait_idle(timeout: float) -> bool` (tests), `stop() -> None`.
- Behavior:
  - `on_utterance`: add to transcript, `writer.write_utterance`, emit `UtteranceAdded`; if auto enabled and source is `them`, submit `detector.check` to a single-thread detection executor; a non-`None` result starts an `auto` hint.
  - `ask_now`: question = `transcript.last_question()`; if `None` emit `Status("No question yet.")`; else start a `hotkey` hint.
  - `ask_with_image`: if `not provider.supports_images` emit `HintError(id, "Selected local model does not support images.")` and stop; else start a `screenshot` hint with question `transcript.last_question() or ""`.
  - Starting a hint: id increments from 1; context = `transcript.window(clock(), context_seconds)`; emit `HintStarted`; run `provider.stream_answer(build_system(profile_text), build_user_text(req), req.image_png, cancel_event)` on a hint thread, emitting `HintDelta` per chunk; on finish `cost.add(provider.model, provider.last_usage)`, `writer.write_hint`, emit `HintDone`; on `ProviderError` emit `HintError(id, str(e))` and `writer.write_error`.
  - Cancel/replace: a new `hotkey`/`screenshot` hint cancels any running hint; a new `auto` hint cancels a running `auto` hint but is dropped if a `hotkey`/`screenshot` hint is running. A cancelled hint is written with its partial answer and the suffix ` _(cancelled)_`.
  - Exceptions inside worker threads never propagate; they become `Status(f"Internal error: {e}")`.
